# NER

**Full Name:** Named Entity Recognition

**中文：** 命名实体识别

## Definition

NER 是从文本中识别实体提及的位置，并将其分类为人名、组织、地点等类型的 NLP 任务。

## Explanation

NER 通常需要同时判断实体边界与实体类别，例如把句子中的“OpenAI”标为组织。它属于信息抽取；识别出提及后再确定其对应的现实实体或知识库条目，则属于 [[Entity Linking]]。

## Common Use

常用于从新闻、论文、客服记录等文本中抽取人物、机构、地点和产品信息，支持搜索、知识图谱构建与文档分析。
