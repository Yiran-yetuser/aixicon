# NLP

**Full Name:** Natural Language Processing

**中文：** 自然语言处理

## Definition

NLP 是让计算机处理、理解和生成人类语言的研究与工程领域。它涵盖从规则、统计方法到机器学习和 [[LLM]] 的多种技术；[[LLM]] 是 NLP 的重要组成部分，但不等同于 NLP。

## Explanation

NLP 关注如何把文本或语言输入转化为计算机可处理的信息，并完成翻译、分类、信息抽取、问答或文本生成等任务。它结合计算机科学、语言学、统计学与机器学习方法，应用范围从搜索和文本分析延伸到现代对话系统。
